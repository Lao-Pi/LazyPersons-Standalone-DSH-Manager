# 考工记

DSH 崩了、起不来的时候用的体检工具。**它不依赖 DSH 活着**——自己跑，浏览器页面当界面。

## 怎么开

双击 `启动.bat`。会弹一个黑窗口（服务在里面跑）和一个浏览器页面。

- **那个黑窗口别关**：关了服务就停。想退出按 Ctrl+C，或者直接关窗口。
- 浏览器没自动弹？把黑窗口里那行 `http://127.0.0.1:19390/` 复制进浏览器。
- 两个考工记同时开，第二个用 19391——不是坏了。

## 里面有什么

**体检**

- **自动体检**：量 DSH 整体完整度——主目录 / profile / `cordis.patch.yml` / `package.json` / 运行时 Node / 会话目录 / 报障目录能不能写 / 里面有几份崩溃报告。（`.credentials.yaml` 只报"存在"，不读内容。）
- **错误日志分析**：自动列出**最近 5 份崩溃报告**，选编号看详细分析。分析分三片：
  - **片①** 一句话摘要 —— 这行可以丢给翻译软件
  - **片②** 原样正文（环境快照 + 错误 + 完整栈）—— 丢给网页端 AI 时**一个字符都别改**
  - **片③** 官方文档网址 —— 和片②一起复制，让 AI 开联网照着找；附带"不要轻信诊断、以你机器上的版本为准"的提醒
  看完会把整段导出到 `导出\`，用记事本打开全选复制就能发出去。

**插件管理**

- **清单**：每个 profile 下的插件，带 **完整度 X/8**。8 项判据是照四个能正常加载的插件定的：`package.json 在` / `有 name` / `有 version` / `type: module` / `main` 指向的入口文件在 / `有 peerDependencies` / `patch 里有注册` / `相对 import 都带扩展名`
- **明细**：逐项列出哪条过、哪条不过
- **删除**：四步都留后路——配置先备份 → 摘掉 patch 里那条注册 → 目录整个移进 `回收\<时间戳>\`（**不是 rm**）→ 复检（目标没了、**别的条目一条没动**、写法没坏）。撤销 = 目录移回去 + 备份的配置覆盖回去，屏幕上会把这两条路径打出来。
  两道阻力：按编号选中 → 输 `d` → **把插件名一字不差打一遍**，才真删。

## 三条原则

1. **只读**：不改 DSH 的配置（除了你点名要删的那个插件的注册）、不删日志、不读凭据文件。写只写 `导出\` 和 `回收\`。
2. **零依赖**：只用 Node 标准库，不装任何东西。
3. **独立**：DSH 是什么状态都不影响它。但它需要 Node——用 DSH 自带的那个。

## 自检 / 命令行

```
node server.mjs --selftest     # 16 项：三个模块 + 删除演练 + 状态机
node server.mjs --no-open      # 起服务但不开浏览器
```

## 平台

Windows（`启动.bat` 是 Windows 脚本）。代码本身是纯 Node，换平台只差一个启动脚本。
