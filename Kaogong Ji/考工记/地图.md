# 考工记 · 地图

DSH 崩了也能用的体检工具。双击 `启动.bat` 就开，浏览器里是一块老式液晶绿屏。
**改东西之前先看这张图，别全翻一遍。**

## 这份地图在包里的位置

```
kaogongji\                         ← 发布包（要上传 GitHub 的就是这一整份）
  package.json / index.ts          ← 插件薄壳：注册 kaogongji / kaogongji_open 两个工具
  LICENSE / 图标.ico / README.md   ← 发行信息（MIT，发行商：小寻）
  考工记\                          ← 本体：下面这张图里的东西，独立运行
    地图.md                        ← 你正在看的这份
```

**壳和本体是两层，别搞混**：本体谁都不依赖——DSH 崩了、没开、插件被删了，双击 `启动.bat` 照样跑；
反过来壳依赖本体在不在，找不到会在工具的返回里明说，不静默。

```
考工记\                     ← 本体
  启动.bat          17 行   找 Node（DSH 自带 → PATH 兜底）→ 跑 server.mjs     ⚠ 必须存成 GBK
  server.mjs       295 行   环境探测（含定位兜底）+ 本地服务 + 状态机 + 开场稿 + --selftest
  modules\
    health.mjs      44 行   自动体检：DSH 整体完整度
    logs.mjs       153 行   错误日志分析：最新 5 份 → 三片 → 导出
    plugins.mjs    219 行   插件管理：行扫描 patch / 完整度 / 一键删除
  web\
    index.html     141 行   液晶绿屏终端（纯 HTML+CSS+JS，无框架）
  README.md         50 行   给用户看的说明书：怎么开 / 有什么 / 三条原则
  图标.ico                  马赛克扳手（做快捷方式时用它）
  地图.md                   本文件（自指，不必数行）
  导出\                     logs.mjs 写这儿：导出一整段可直接发给网页 AI 的文本
  回收\                     删除时东西挪这儿（第一次删才建）——删除不是 rm
```

## 一条输入走过的路

```
双击 启动.bat
 └ 找 Node → 跑 server.mjs
    ├ 探测环境 env（主目录 / profile / 报障目录 / Node / 会不会写）← 全项目只在这算一次
    ├ 起服务 127.0.0.1:19390（被占就 +1，最多试 20 个）
    └ 开浏览器 → web/index.html（开场稿打字机 → 主菜单）
          │  GET  /api/boot  → 开场稿 + 菜单
          │  敲数字 + 回车   → POST /api/in {text}
          └──────────────────────────────┐
                                         ↓
                        handle(text)  ← 状态机，五个视图
                        menu → check → logs
                             → plugin-list → plugin-detail → plugin-del
                                         ↓
                          调模块 → 模块返回 lines[]（纯文本行）
                                         ↓
                          前端逐行打印（打完才解锁输入框）
```

**为什么状态机放服务端**：输出是纯文本流，人看是界面，复制出去就是给 AI 的料——同一套数据不用写两份渲染。

## 插件管理怎么工作

**清单**（`plugins.inventory`）：扫每个 profile 的 `plugins\*` 目录，逐个去 patch 里配对注册。

**完整度 8 项**（`plugins.integrity`）——判据是照**四个能加载的插件**定的，不是编的：
`package.json 在` · `有 name` · `有 version` · `type: module` · `main 指向的入口文件在` · `有 peerDependencies` · `patch 里有注册` · `相对 import 都带扩展名`

**一键删除**（`plugins.removeOne`）——四步，每步可逆：
1. 配置先备份到 `回收\<时间戳>\cordis.patch.yml`
2. 从 patch 摘掉那条注册（`insert` 块里只有它一个，就连 `insert` 行一起摘）
3. 插件目录整体 `rename` 进 `回收\<时间戳>\plugins\<名字>\`（**不是 rm**）
4. 复检：配置还能读、目标注册没了、三类致命写法没有

撤销 = 目录移回去 + 备份的配置覆盖回去（界面上会把两条命令打出来）。
**两道阻力**：按编号选中 → 输入 `d` → **把插件名一字不差打一遍**，才真删。

## 想改什么 → 动哪儿

| 想改什么 | 去哪儿 |

| 开场稿（讲考工记那段） | `server.mjs` 的 `QUOTE` |
| 体检查什么 | `modules\health.mjs` 的 `scan()` 里加 `check(条件, 好的话, 坏的话)` |
| 错误类型怎么认 | `modules\logs.mjs` 的 `TYPE_RULES` |
| 已知案例库（踩过的坑） | `modules\logs.mjs` 的 `CASES` |
| 官方文档网址 | `modules\logs.mjs` 的 `DOCS` / `REPO` |
| 分片文案、"不要轻信"那段 | `modules\logs.mjs` 的 `detail()` |
| 列表显示最新几份 | `logs.list(env, 5)` 里那个 5 |
| 插件完整度判据 | `modules\plugins.mjs` 的 `integrity()`（`add(...)` 一行一项） |
| 删除的步骤 / 复检 | `modules\plugins.mjs` 的 `removeOne()` |
| patch 行扫描（认 id/name/insert） | `modules\plugins.mjs` 的 `readPatch()` |
| patch 三类致命写法 | `modules\plugins.mjs` 的 `checkPatchSyntax()` |
| 终端配色 / 网格 / 字体 | `web\index.html` 的 `:root`（`--lcd` 前景、`--bg` 背景、`--grid` 点阵缝） |

| 端口范围 | `server.mjs` 的 `PORT0`（19390） |
| 启动方式 / 找 Node | `启动.bat` 第 4 行 |

## 想让整套输出变成英文？（给服务英文用户的 AI）

**不用改代码结构，全是字符串。** 翻完下面这几处，界面、菜单、报告、导出的文本会**一起**变英文。

| 文件 | 翻哪几处 | 说明 |
|---|---|---|
| `web\index.html` | `<title>`、`#head` 的标题块、`#foot` 版权行、`#busy` 的「正在输出…」、提示符 `考工记&gt; ` | 纯展示层，改文字就行 |
| `server.mjs` | `QUOTE`（开场稿，最长的一块）、`MENU`、`CHECK`、`handle()` 里所有提示串、`pluginListLines()` 和 `pluginDetailLines()` | 状态机所有的回话都在这儿 |
| `modules\health.mjs` | `scan()` 里的检查项文字（`[ OK ]` / `[ !! ]` 标记可以留着） | |
| `modules\logs.mjs` | `detail()` 里片①②③的标题和提示语、`CASES` 的案例说明 | |
| `modules\plugins.mjs` | `integrity()` 的 8 项名称、`scan()` 和 `removeOne()` 的报告文字 | |
| `启动.bat` | 找不到 Node 的那几句提示 | ⚠️ **改完必须存回 GBK + CRLF**，否则整个脚本会碎（见「已知坑」） |

**两个别动的地方**：

- `logs.mjs` 的 `DOCS` / `REPO`（官方文档网址）**别翻**——那是给网页 AI 开联网照着查的锚点，翻了就指错路。
- 崩溃报告里 `--- error ---` 那一段**别翻**——原始报错是要拿去搜、拿去问人的，翻过的版本搜不到东西。

翻完可以跑一次 `node 考工记\server.mjs --selftest`——自检项里有一半是中文文案的字符串匹配，**它会失败**（那时你把自检里对应的期望字符串一起改了就行）。

## 铁律

- **只读 DSH**：不改配置（除了你点名要删的那个插件的注册）、不删日志、不读 `.credentials.yaml`（只报它存在）。写只写 `导出\` 和 `回收\`。
- **删除 = 挪进回收**，永远不 rm；配置也留备份。
- **零依赖**：只用 Node 标准库，不装任何东西。
- **独立**：DSH 崩着、没开都能跑（但机器上得有 DSH 自带的 Node）。
- **没输出完不许输入**：前端 `lock(true/false)` 锁输入框——乱敲会让"现在在答哪个问题"错位。

## 已知坑（改的时候别踩）

- **`启动.bat` 必须 GBK + CRLF**：cmd 按 GBK 读 bat，存 UTF-8 会把中文行切碎、整个脚本报"不是内部或外部命令"。
- **动 patch = 正在跑的 DSH 会立刻热重载**（2026-10-13 实测：改完 47 秒后插件重载）。所以**删插件之前最好先关掉 DSH**。
- **终端不适合刷长文本**：181 KB 的崩溃报告只打印前 28 行，全文写进 `导出\`。
- **崩溃报告文件名里是 UTC**，显示一律换算成本地时间。
- **端口自增**：两个考工记同时开，第二个用 19391，不是坏了。

## 出处（开场稿那段的考据）

《周礼》冬官亡佚、河间献王刘德取《考工记》补入、六类三十个工种、"六齐"合金配方、"匠人营国"——
取自人民网《讽刺与幽默》2023-11-10《〈考工记〉：中国第一部工科巨著》：
<http://paper.people.com.cn/fcyym/html/2023-11/10/content_26028390.htm>
（外来读物只进这张地图，不进家规——`work\work.md` 第七节。）

**右下角版权行写"春秋战国"、不写具体年份**：《考工记》成书年代学界有分歧——人民网那篇说"春秋战国时期的典籍"，另有"齐国官书 / 稷下学宫"一说，但 1984 年就有专文《〈考工记〉不是齐国官书》反驳它。**没有公认的单一公元年**，所以不冒充精确。（最初的设想是把年份换成成书年代，查完改成了现在这个写法。）
